# Settings 设计

Me Tab 右上角只保留齿轮入口（移除搜索、归档）。Settings 为独立二级页：iOS 原生分组列表 + Mosaic 视觉语言，配置项下沉到二级/三级页，首页约 10 个入口。

图例：`›` 进入下一页 · `[值]` 右侧状态 · `[开关]` Switch · `⇢` 页内子项摘要 · 缩进即层级

## 2. 右侧 value 展示逻辑

`MosaicListRow` 统一为 `title / subtitle · value · trailing`，value 只读，不承载点击。

| 行类型 | 右侧展示 | 交互 |
| --- | --- | --- |
| 跳转 | `value` + `›` | push 二级页 |
| 开关 | 仅 `Switch`，不显示 value | 即时生效 |
| 单选 | 一级显示当前值，二级用 `✓` | 打开选择列表 / 页内切换 |
| 只读 | 纯文本 | 无点击、无箭头 |
| 危险 | 红色 title，无箭头 | 二次确认 |

- **值来源**：一律取当前生效配置；未设置/未绑定用 placeholder「未设置」（subtle 色）。
- **跟随系统**：value 显示「跟随系统」，实际生效值（浅色/深色、解析后的语言）放在二级页副标题说明。
- **脱敏**：手机号 `138****8888`、邮箱 `m***@mail.com`；只读展示，不支持长按复制。
- **权限类**：展示系统真实状态（已授权/未授权/受限），点击跳系统设置，不用 App 内开关伪装。
- **长度**：单行、最大 40% 宽、尾部省略；value 文案走 i18n，不硬编码。
- **联动**：主题/语言等值变更后，所有页面的 value 与标题立即刷新（zustand 订阅）。

## 3. 二级 / 三级页面

- **二级页**：`MosaicScreenHeader` + 分组 `MosaicCard/MosaicList` + 组说明 + 页脚危险操作；同一页面内不放无关开关。
- **三级页**：单一任务（选择项、编辑表单、授权详情、导出/注销向导），只保留「返回 + 保存/确认」。
- **全局默认 vs 单条记录**：隐私、AI 权限在 Settings 只设默认值，单条记录仍可覆盖。

## 4. MVP 范围

必须：个人资料与账号安全、外观与显示、通知与提醒、记录偏好、AI 数据使用、应用锁与系统权限、数据导出。
后续：多数据源自动同步、AI 记忆/画像管理、完整备份恢复、高级数据删除与迁移。
